## Featured projects

**[Fabric Defect Inspection](https://github.com/ammaran620-de/Febric-Defect)** ([live demo](https://ammaran620-de.github.io/Febric-Defect/))
YOLOv8n defect detection for textile images with a FastAPI service, an inspection log and a dashboard. F1 0.869 on 80 held-out images, against 0.093 for an OpenCV baseline. The demo runs the model in your browser.

**[Industrial Anomaly Detection MLOps](https://github.com/ammaran620-de/industrial-anomaly-detection-mlops)**
PatchCore detector trained on defect-free images only, served with FastAPI and tracked in MLflow. Image AUROC 0.9956 on MVTec AD carpet (coreset ratio 0.05, 320 px). The README documents the score overlap behind the four errors and the gap to real-time latency.

**[SiteSignal Delay Intelligence](https://github.com/ammaran620-de/sitesignal-delay-intelligence)**
Construction delay analysis on synthetic project data. A deterministic critical-path engine does the schedule maths and is tested without any model; an LLM agent selects tools and explains the results.

**[Ayah Feedback Lab](https://github.com/ammaran620-de/ayah-feedback-lab)**
Research prototype: can a speech model get every word right and still miss a pronunciation error? Whisper wording check plus an acoustic classifier on two ayahs, evaluated on 144 held-out clips with its false flags shown. Not a teaching tool.
