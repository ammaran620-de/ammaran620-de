## Featured projects

**[Fabric Defect Inspection](https://github.com/ammaran620-de/Febric-Defect)** ([live demo](https://ammaran620-de.github.io/Febric-Defect/))
YOLOv8n defect detection for textile images with a FastAPI service, an inspection log and a dashboard. F1 0.869 on 80 held-out images, against 0.093 for an OpenCV baseline. The demo runs the model in your browser.

**[SiteSignal Delay Intelligence](https://github.com/ammaran620-de/sitesignal-delay-intelligence)**
Construction delay analysis on synthetic project data. A deterministic critical-path engine does the schedule maths; an LLM agent only selects tools and explains results, with cited evidence.

**[Industrial Anomaly Detection MLOps](https://github.com/ammaran620-de/industrial-anomaly-detection-mlops)**
PatchCore detector trained on defect-free images only, served with FastAPI and tracked in MLflow. Image AUROC 0.9956 on MVTec AD carpet. The README documents the score overlap behind the four errors and the 535 ms CPU latency.

**[EHR Review Desk](https://github.com/ammaran620-de/ehr-review-desk)**
Streamlit dashboard that flags unusual access patterns in synthetic health-record data with Isolation Forest and SHAP explanations. Metrics are limited to the synthetic set.
